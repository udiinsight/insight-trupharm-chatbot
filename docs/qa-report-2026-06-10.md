# Conversation QA Report — 2026-06-10

Scripted multi-turn QA of the SUGAR360 (Tropharm) chatbot on staging, per the
"אסטרטגיה שיחתית" spec (15–20 conversation scripts before go-live, tone suited
to a sensitive audience, no pushiness). Run AFTER deploying the objection
playbook (prompt 9,874 chars) and the v1.0.6 conversation-memory fix.

## Result: 30/30 turns PASS (20 scripts)

- **Mechanical checks** (per turn, scripted in [qa-scripts.json](qa-scripts.json)):
  disclaimer kind, required/forbidden action types, contact-channel presence,
  product-page CTA on buy intent, empty-actions on emergency, forbidden/required
  response text (regex, evaluated server-side), English-language check, WhatsApp
  summary presence + topicality, source counts (warn-level).
- **Tone judge** (LLM, server-side; 16 judged turns): pushiness 1–2 on a 1–5
  scale (mostly 1), tone appropriate on **100%** of judged turns. Recurring
  judge notes: "honest", "warm", "balanced", "no pressure", "appropriately
  defers to medical team".

## Notes

1. One initial flag (S20.t3) was a **test false-positive**: the bot correctly
   told a callback-requesting user to initiate contact via WhatsApp/phone
   ("…and they will get back to you") — honest, no agency claimed. The test
   regex was narrowed to only catch bot-arranged callbacks ("leave details and
   we'll call you"); re-run passed.
2. Latency: 7–26s per full non-streaming turn server-side (the widget streams,
   so perceived first-token latency is much lower).
3. Full transcripts (Hebrew) are NOT committed: `.tmp-extract/qa-transcripts-2026-06-10.jsonl`
   (local) / `/tmp/itc_qa_results.jsonl` (staging, temporary) — review there.

## How to re-run

```
# upload docs/qa-scripts.json + cli/qa-conversations.php to /tmp/itc_qa/ (base64 pipe), then:
cd public_html
ITC_QA_SCRIPTS=/tmp/itc_qa/qa-scripts.json ITC_QA_FROM=1 ITC_QA_TO=10 \
  wp eval-file /tmp/itc_qa/qa-conversations.php --user=1
```

Run in batches (~5 scripts ≈ 2–3 min each). Stdout is an ASCII scorecard;
transcripts append to `/tmp/itc_qa_results.jsonl` (last record per script.turn wins).
